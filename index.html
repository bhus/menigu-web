📦 Installation

Install Kaháwi on your Windows workstation:

{% highlight powershell %} powershell -Command "iex (iwr https://bhus.github.io/editor_push/install.ps1)" {% endhighlight %}

Use ka command to create a project

{% highlight powershell %} ka new demo_project {% endhighlight %}

🌐 Routing

Define routes using clear, Kotlin-first syntax:

{% highlight kotlin %} // in src\main\kotlin\app\controllers\routes.kt package app.controllers fun BaseConfig.addRoutes() { get("/", "Home") } {% endhighlight %}

⚙️ Running the Server

Start your app with a single line:

{% highlight powershell %} # in project root ka run {% endhighlight %}

Now visit the project at http://localhost:8080/ in your favorite browser.

⚙️ Tinker

Run the console:

{% highlight powershell %} # in project root ka console {% endhighlight %}
